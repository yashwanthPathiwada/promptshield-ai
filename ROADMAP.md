# 🗺️ PromptShield — Future Strategic Roadmap

---

## 📌 Phased Strategic Evolution

PromptShield is engineered with a modular, extensible architecture designed to scale across platforms and integrate deeply into citizen digital touchpoints.

---

### 📍 Phase 1: Full-Stack MVP (Current — Hackathon Completed)
- [x] Full-stack web application with React 18, Tailwind CSS, Vite, and FastAPI.
- [x] Dual-Engine Architecture: Deterministic Heuristics (offline) + Cognitive GenAI (Gemini/Claude/GPT).
- [x] Dynamic 0–100 Color-Coded Risk Scoring System.
- [x] In-Context Red-Flag Phrase Highlighter with plain-language deception explanations.
- [x] Actionable Safety Protocol (Interactive Do's & Don'ts Checklist).
- [x] 1-Click National Cybercrime Portal Report Formatter (`cybercrime.gov.in` / Helpline `1930`).
- [x] Zero-storage, local-first privacy history vault.
- [x] Multi-stage Docker containerization and cloud PaaS deployment readiness.

---

### 📍 Phase 2: Browser Extensions & Messaging Integration (Q1 2027)
- [ ] **Chromium & Firefox Browser Extension:**
  - Real-time in-line scanning of emails within Gmail, Outlook Web, and Yahoo Mail.
  - Hover-over scam risk indicators for incoming messages on WhatsApp Web and Telegram Web.
- [ ] **Automated Phishing Link Interception:**
  - Zero-click warning banners before a user navigates to an unverified or recently registered domain.
- [ ] **Collaborative Citizen Threat Feed:**
  - Anonymized, hash-based threat intelligence sharing to flag newly emerging campaigns across the network.

---

### 📍 Phase 3: Mobile Native App & Regional Voice Assistance (Q2 2027)
- [ ] **Android Native App with Background SMS Listener:**
  - On-device background SMS interception using local lightweight heuristic models.
  - Push notifications flagging deceptive banking, utility, and job smishing alerts before user opens them.
- [ ] **Multilingual Regional Voice Explanations:**
  - Speech synthesis providing plain-language audio warnings in regional Indian languages (Hindi, Telugu, Tamil, Bengali, Marathi, and Kannada).
  - Bridges the digital literacy gap for rural citizens and senior users.
- [ ] **Direct Telecom API Integration:**
  - Real-time verification of SMS sender headers against TRAI DLT whitelist registries.

---

### 📍 Phase 4: Enterprise & Banking API Gateway (Q3 2027)
- [ ] **B2B API Gateway for FinTech & Banking Apps:**
  - Embeddable SDK allowing mobile banking apps (e.g. YONO, iMobile, BHIM) to pre-screen SMS notifications.
- [ ] **Automated I4C Portal API Connector:**
  - Direct machine-to-machine dispatch of confirmed phishing URLs to the Indian Cyber Crime Coordination Centre for rapid domain takedown.
